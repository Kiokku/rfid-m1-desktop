# Domain Docs

This project uses a single domain context for RFID M1 墨盒授权.

## Before working in this context

- Read `docs/domain/CONTEXT.md` and use its preferred business terms.
- Read the relevant decisions in `docs/design/adr/`.
- Treat `docs/design/RFID_M1墨盒授权方案.md` as the common card, key and protocol contract.
- For desktop work, also read `docs/design/RFID_M1授权加密桌面端子方案.md`.

Do not silently override an ADR. Record a new decision when an implementation choice intentionally changes an existing one.
