# Issue tracker: Local Markdown

Issues and specs for this project live as Markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`.
- The feature specification is `.scratch/<feature-slug>/spec.md`.
- Implementation issues are individual files under `.scratch/<feature-slug>/issues/`, numbered from `01`.
- A `Status:` line near the top records the triage state.
- Comments and conversation history are appended under `## Comments` when needed.

## Publishing

When a skill publishes a specification or issue, it creates or updates the corresponding file under `.scratch/`. The current desktop effort uses `.scratch/rfid-m1-desktop/`.
