# 以统一密钥材料接口替代操作任务接口

RFID 后端保留客户注册、客户查询、客户密钥和工厂根密钥，只通过 `POST /api/rfid/key-material` 按 `customer_id` 和可选 `cartridge_id` 返回短时 `Key A`/`Key B`。授权创建/完成、储值创建/完成和喷码机配置创建/取材料/提交结果共 7 个接口被删除；`cartridge_id` 由桌面端本地安全生成，授权、储值和喷码机配置均在本地验收，结果不上传后端。

## Consequences

- 继续保留每卡 `Key B` 派生模型；只有请求包含 `cartridge_id` 时才返回 `Key B`，喷码机配置只取得 `Key A`。
- 储值需要先按操作员所选客户取得 `Key A` 并读取卡内 `cartridge_id`，再调用同一接口取得对应 `Key B`。
- 后端不再提供墨盒编号全局唯一约束、重复 UID 检查、储值任务幂等、结果不确定阻断或操作审计。
- 桌面端必须在单次操作内防止重复写卡或加值；发生结果不确定时仍以贴标并退出流转作为人工边界。
