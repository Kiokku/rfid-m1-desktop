# 备选：通过 Web Serial 直连 USB 虚拟串口读卡器

授权、储值桌面端采用独立桌面技术栈开发，具体实现不由主方案约束。若当前桌面端无法满足读卡器接入需求，可将 Web Serial 作为备选：使用 Chrome 或 Edge，在 `HTTPS` 或 `localhost` 安全上下文中通过 Web Serial API 与读卡器的 USB 虚拟串口通信。

记录该备选是因为读卡器已确认使用 USB 虚拟串口，且授权操作发生在受控的固定工位。是否启用该方案由桌面端实施方另行决定，不构成主方案的技术要求。

## Consequences

- 启用时，授权工作站限定为支持 Web Serial 的 Windows Chrome 或 Edge；不支持 Firefox 和 Safari。
- 启用时，浏览器不能静默枚举或自动打开串口；界面必须引导操作员选择正确的读卡器。
- 启用前，必须以实际设备验证串口稳定性、断连恢复及 `AA` 帧收发兼容性；验证失败时应选择其他桌面端读卡器接入方式。
