# 以卡片验收结果完成授权记录

RFID 后端先创建进行中的授权任务，预分配 `cartridge_id` 和任务有效期。桌面端完成写卡后，使用 `Key A` 和 `Key B` 回读、验证身份块和次数值块，再将验收数据提交后端；仅此时后端把任务标记为授权成功。同一 `task_id` 最多生成一条成功记录，重复提交返回原结果。

网络、桌面端或读卡器在不可逆写卡之后、提交之前中断时，后端不得将任务标记为成功，桌面端提示“结果不确定”。为缩减第一版开发内容，不提供待核验查询、回读恢复或软件隔离接口；操作员必须将墨盒贴标并退出流转，且不得复用已分配的 `cartridge_id`。

## Consequences

- 后端授权记录不会将未验收卡片误标为成功。
- 桌面端只需提供成功、失败或结果不确定的最小状态提示。
- 结果不确定的墨盒依赖人工保管或报废，第一版无法通过软件恢复，存在耗材损失。
- 该状态机只覆盖出厂授权，不改变喷码机第一版“成功回调后扣减、不补扣”的运行策略。
