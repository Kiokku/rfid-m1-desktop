# 采用离线 M1 墨盒授权与两层密钥

喷码机在运行期间离线且一机一客户，因此采用客户 `Key A` 进行日常墨盒认证与扣减、由工厂根密钥按墨盒编号派生每卡唯一 `Key B` 进行出厂管理。余额存放在 M1 值块中；这牺牲了对 M1 Classic/F08 克隆攻击的强防护，换取离线可用和现有读写器协议的直接支持。

## Consequences

- 客户密钥泄露时需通过受控维护重新配置喷码机并重新授权墨盒；第一版不支持在线自动轮换。
- UID 不能作为防伪凭据；系统以客户密钥认证、卡内墨盒编号和受保护值块为离线控制边界。
- 已成功喷码后发生断电或读卡失败时，第一版不补扣，可能出现一次未计数喷码。
