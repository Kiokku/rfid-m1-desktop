# 后端保管授权密钥，桌面端仅短时使用

客户 `Key A`、工厂根密钥和由其派生的每卡 `Key B` 保存在后端的加密密钥库中。已登录并获授权的操作员创建单张墨盒授权任务时，后端仅为该任务通过 HTTPS 下发所需密钥材料；桌面端使用读卡器执行 M1 认证和写卡，密钥只存在于桌面端进程运行内存中，完成或超时即清除。

选择该方案是因为读卡器由桌面端直连，后端无法替代桌面端执行卡片认证；同时将长期密钥的持久化、审计和访问控制集中在服务端。

## Consequences

- 授权工作站必须是受控终端；桌面端进程被攻破时，进行中的授权任务密钥可能泄露。
- 桌面端不得将密钥写入本地持久化存储、会话恢复数据、错误上报或日志。
- 后端接口须限制操作员权限、任务有效期和一次性使用，并审计授权结果。
