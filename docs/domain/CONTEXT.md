# 墨盒 RFID 授权

该上下文定义喷码机离线识别、授权和消耗墨盒额度时使用的业务术语。

## Language

**客户**:
使用喷码机和获授权墨盒的组织。一台喷码机仅服务一个客户。
_Avoid_: 租户

**客户密钥**:
为一个客户随机生成、用于认证其墨盒 M1 扇区的密钥；仅在该客户已授权的喷码机中保存。
_Avoid_: 通用密码, 固件密码

**喷码机**:
仅在组装或出厂阶段联网配置、运行期间离线的设备。它只保存其服务客户的授权材料。
_Avoid_: 读卡器

**墨盒**:
附有 M1 卡贴、具有独立编号和可喷码次数的耗材单元。
_Avoid_: 卡, 标签

**喷码成功回调**:
喷码机确认一次喷码已经完成的设备事件。它是扣减墨盒可喷码次数的业务触发条件。
_Avoid_: 喷码开始, 喷码请求

**扣减策略**:
第一版在收到喷码成功回调后立即扣减一次可喷码次数，不实现待扣减记录、补扣或断电恢复。
_Avoid_: 两阶段扣减

**可喷码次数**:
墨盒剩余可执行喷码成功回调的次数，作为 M1 值块中的唯一权威余额。
_Avoid_: 普通数据块计数器

**F08 卡贴**:
安装在墨盒上的 ISO/IEC 14443A、13.56 MHz M1 Classic 1K 兼容抗金属标签。其 UID 仅用于索引和一致性校验，不是防伪凭据。
_Avoid_: 不可复制身份卡

**授权工作站**:
出厂阶段使用读卡器初始化 F08 卡贴、写入墨盒授权信息，并为喷码机配置其客户密钥的受控软件。
_Avoid_: 喷码机

**授权任务**:
针对一个指定客户和初始可喷码次数执行的一次墨盒初始化操作；只有卡片验收通过后才成为成功授权记录。
_Avoid_: 预授权, 批处理任务

**结果不确定**:
卡片已经发生不可逆写入或加值，但桌面端未能取得并提交可信验收结果的状态。第一版不提供恢复或软件隔离功能，墨盒必须贴标并退出流转。
_Avoid_: 授权成功, 可重试, 可忽略失败

**客户密钥库**:
后端持有的受保护记录，用于保存客户标识、密钥版本和加密后的客户密钥。
_Avoid_: 明文密钥文档

**系统管理员**:
由现有云平台管理、可登录桌面端并执行客户注册、墨盒授权和储值的操作员；其登录凭据不用于卡片认证或密钥库加密。
_Avoid_: 客户密钥持有者, 喷码机用户

**云平台**:
目前已运行的公司内部管理平台，负责桌面端操作员账号、登录会话和客户主数据。RFID 后端通过其现有接口校验会话并注册、查询客户。
_Avoid_: RFID 密钥库, 新建账号系统

**工厂管理密钥**:
仅由授权工作站使用的 M1 扇区管理密钥，用于初始化卡片和修改扇区尾块；喷码机不持有该密钥。
_Avoid_: 客户密钥

**每卡管理密钥**:
由工厂根密钥和墨盒编号派生的工厂管理密钥。它只对应一张墨盒，不在客户密钥库逐张存储。
_Avoid_: 全局工厂密码

**密钥版本**:
标识客户密钥版本的卡内字段。第一版固定为 `1`，仅保留字段，不提供密钥变更功能。
_Avoid_: 在线密钥轮换
