# 12 — 完成真机异常与结果不确定处置

**What to build:** 在 Windows 真机流程中验证写入、移卡、串口断连和接口中断边界，使系统管理员能明确区分可重试失败与必须贴标退出流转的结果不确定。

**Blocked by:** 09 — 走通真实墨盒授权；11 — 走通真实墨盒储值

**Status:** ready-for-agent

- [ ] 授权写块 7 前失败不会生成成功记录，并允许在当前安全操作中重试。
- [ ] 块 7 可能已写入后无法可信验收时显示“结果不确定”，不提供重新授权入口。
- [ ] 储值可能已执行后中断时显示“结果不确定”，后端保留未完成任务并阻止再次储值。
- [ ] 界面要求贴标并退出流转，不提供待核验、恢复、软件隔离或解除入口。
- [ ] 真实移卡、串口断连和接口中断场景均不误报成功。
