# 06 — 接入云平台真实登录与会话校验

**What to build:** 在 Windows 环境让系统管理员使用云平台真实账号登录，并让 RFID 后端验证 token 与授权工位权限，使后续真实业务接口共享可信会话。

**Blocked by:** 02 — 使用后端 Mock 完成登录纵切；05 — 迁移 Windows 环境并连接真实读卡器

**Status:** ready-for-agent

- [ ] 桌面端使用云平台真实用户名密码接口取得 token。
- [ ] RFID 后端拒绝失效 token、无权限账号和缺少授权工位权限的会话。
- [ ] token 只存在 Electron 主进程内存，且注销、失效和退出时清除。
- [ ] 请求、响应、日志和错误上报不包含密码或完整 token。
- [ ] 应用重启后必须重新登录。
