# 04 — 固化 AA 协议并准备 Windows 迁移

**What to build:** 在 macOS 完成读卡器 `AA` 帧协议和所需 M1 命令的纯字节编解码，并形成可复现的 Windows 开发环境迁移检查清单，使真实串口接入成为下一步容易验证的工作。

**Blocked by:** 01 — 建立 Electron 安全桌面端骨架

**Status:** ready-for-agent

- [ ] 固定字节帧覆盖递增序号、大端长度、XOR 校验、拆包、粘包和错误响应。
- [ ] 已定义寻卡、认证、块读写、值块初始化、加值和读值所需的命令载荷与响应解析。
- [ ] 编解码错误会产生明确的类型化结果，不记录密钥或完整敏感卡块。
- [ ] macOS 运行不会加载或打开 SerialPort，也没有应用级 `MockReader`。
- [ ] Windows 检查清单覆盖 Node/构建工具、串口驱动、读卡器、废弃 F08 样卡和启动验证。
