# 07 — 完成真实客户注册与查询

**What to build:** 让系统管理员在 Windows 桌面端通过 RFID 后端调用云平台真实客户接口，完成客户注册、RFID 映射和安全密钥初始化，并可查询使用。

**Blocked by:** 03 — 使用后端 Mock 完成客户管理纵切；06 — 接入云平台真实登录与会话校验

**Status:** ready-for-agent

- [ ] 客户注册成功后保存唯一 `cloud_customer_id` 并分配唯一 32 位 `customer_id`。
- [ ] RFID 后端生成密码学随机的 6 字节客户密钥，以认证加密形式保存并固定 `key_version = 1`。
- [ ] 云平台注册成功但本地初始化失败时，重试不会再次注册客户或生成第二把密钥。
- [ ] 客户查询返回名称、两种客户标识、状态和密钥版本，不返回任何密钥材料。
- [ ] 桌面端真实客户页面与后端接口完成端到端验证。
