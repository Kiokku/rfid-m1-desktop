# 10 — 完成本地储值编排

**What to build:** 在 Windows 环境使用统一密钥材料接口和读卡器完成储值编排：先按所选客户取得客户密钥并读取卡内墨盒编号，再取得每卡管理密钥并在本地回读验收余额增量。

**Blocked by:** 09 — 走通真实墨盒授权

**Status:** ready-for-agent

- [ ] 以所选 `customer_id` 取得客户密钥，认证后读取并校验卡内 `customer_id`、`cartridge_id`、UID、格式版本、密钥版本和 CRC32。
- [ ] 再以 `customer_id` 和卡内 `cartridge_id` 取得每卡管理密钥；两类密钥只在当前主进程操作中短时存在。
- [ ] 单次操作只允许下发一次加值命令，并立即回读余额。
- [ ] 前后余额差与本次输入完全一致且其他资料未变化时才显示成功。
- [ ] 结果不确定时禁止在当前操作内再次加值，提示贴标并退出流转；结果不上传后端。
