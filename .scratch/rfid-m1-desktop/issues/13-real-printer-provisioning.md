# 13 — 完成喷码机受控配置

**What to build:** 在 Windows 环境让系统管理员选择喷码机和客户，通过真实 RFID 后端取得短时配置材料，调用喷码机真实受保护接口并回传审计结果。

**Blocked by:** 07 — 完成真实客户注册与查询

**Status:** ready-for-agent

- [ ] 只有有效且具备权限的会话可以创建喷码机配置任务。
- [ ] 配置材料只包含客户编号、固定密钥版本 `1`、客户密钥和布局版本。
- [ ] 桌面端不接收或传递工厂根密钥和每卡管理密钥。
- [ ] 配置材料只短时存在主进程内存，并在完成、失败、超时或退出时覆零。
- [ ] 配置结果完成审计，日志和错误上报不包含客户密钥。
