# 13 — 完成喷码机受控配置

**What to build:** 在 Windows 环境让系统管理员选择喷码机和客户，通过统一密钥材料接口取得客户 `Key A`，调用喷码机真实受保护接口并在本地验证结果。

**Blocked by:** 07 — 完成真实客户注册与查询

**Status:** ready-for-agent

- [ ] 只有有效且具备权限的会话可以取得目标客户的密钥材料。
- [ ] 配置材料只包含客户编号、固定密钥版本 `1`、客户密钥和布局版本。
- [ ] 桌面端不接收或传递工厂根密钥和每卡管理密钥。
- [ ] 配置材料只短时存在主进程内存，并在完成、失败、超时或退出时覆零。
- [ ] 配置结果只在本地验证，不上传后端；日志和错误上报不包含客户密钥。
