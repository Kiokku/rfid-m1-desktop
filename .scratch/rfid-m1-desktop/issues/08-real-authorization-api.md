# 08 — 完成真实授权任务接口

**What to build:** 在 Windows 环境交付真实授权任务创建与完成接口，使一个已登录系统管理员可以取得一次性授权材料，并且只有可信回读验收才能生成成功授权记录。

**Blocked by:** 07 — 完成真实客户注册与查询

**Status:** ready-for-agent

- [ ] 创建接口生成唯一 `task_id`、不可复用的全局唯一 `cartridge_id` 和进行中任务。
- [ ] 创建响应一次返回任务数据、客户密钥和按既定 HMAC 规则派生的每卡管理密钥，不存在独立材料接口。
- [ ] 密钥库密文、部署主密钥边界、禁止缓存和日志脱敏符合规格。
- [ ] 完成接口校验 UID、块 4/6、余额和双密钥认证结果后才生成成功记录。
- [ ] 同一 `task_id` 重复完成返回原结果且不重复记账，审计不包含明文密钥或完整卡块。
