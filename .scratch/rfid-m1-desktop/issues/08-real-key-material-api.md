# 08 — 完成真实密钥材料接口

**What to build:** 在 Windows 环境交付统一密钥材料接口，使已登录系统管理员可按客户编号和可选墨盒编号取得短时 `Key A`/`Key B`，且不创建或保存授权、储值、喷码机配置记录。

**Blocked by:** 07 — 完成真实客户注册与查询

**Status:** ready-for-agent

- [ ] `POST /api/rfid/key-material` 接受 `customer_id` 和可选 `cartridge_id`。
- [ ] 响应返回客户编号、固定密钥版本 `1`、客户密钥；提供 `cartridge_id` 时按既定 HMAC 规则同时返回每卡管理密钥。
- [ ] 密钥库密文、部署主密钥边界、禁止缓存和日志脱敏符合规格。
- [ ] 失效或无权限会话被拒绝；响应不返回工厂根密钥。
- [ ] 调用接口不会创建或更新授权、储值、喷码机配置记录。
